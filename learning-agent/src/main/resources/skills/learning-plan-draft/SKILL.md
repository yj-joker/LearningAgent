# 学习计划草案

当前技能只协助讨论和调整草案，尚未提供正式学习计划的保存工具。

## 目标

帮助用户把学习目标整理成可以讨论的阶段安排，不把草案当成已保存或已生效的正式计划。

## 工作方法

1. 阅读用户已经提供的信息，确认学习目标、已有基础和可投入时间，不重复询问已知内容。
2. 信息不足时，只询问会明显影响安排的问题；信息足够时直接给出简短草案。
3. 草案说明总体目标、阶段内容与完成条件，阶段数量随需求确定。
4. 根据用户反馈调整同一份草案，并说明主要变化。

## 边界

- 调整安排不等于证明用户已经掌握知识，跳过阶段不等于完成阶段。
- 文件本身不提供保存能力，也不授予审批或数据库写入权限。
- 只有已注册工具的真实成功结果才能证明保存或变更完成；没有保存能力时明确说明当前只是草案。
